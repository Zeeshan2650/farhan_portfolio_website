# Phase 2: Visual Design

Status: Waiting for approval before Phase 3 (frontend development)

The visual direction is published as a design canvas with ten mockups:

1. Home (light mode, full length)
2. Style guide (colours, typography, controls, status labels)
3. About
4. Experience timeline (roles expand to show responsibilities)
5. Technical expertise (air quality first and largest)
6. Projects portfolio (working sector filter and search, plus the project detail layout)
7. Blog
8. Contact (working form with validation messages)
9. Admin dashboard overview
10. Home hero in dark mode

Canvas link: https://claude.ai/artifact/BxeiEnScN3UuEU964wp3VE

## Content rules used in the mockups

1. Every name, date, project, responsibility and parameter is taken from the CV.
2. Statistics are counts of CV content: almost 5 years, 16 client engagements, 8 sectors, 12 instruments.
3. Photographs are shown as labelled placeholders until real photos are uploaded.
4. Blog cards use bracketed placeholders because no articles exist yet.
5. The wind rose on the expertise page is a layout example only and is labelled as such.
6. Project overview and methodology stay empty until written in the dashboard.
